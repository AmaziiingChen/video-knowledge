# 设置界面审阅包

此目录是静态审阅副本，不参与应用构建，也不会修改原始界面文件。

- `settings-review.html`：可直接用浏览器打开的设置界面结构预览。
- `settings-review.css`：预览所用样式。
- 原始实现来源：`frontend/src/components/SettingsDialog.vue`、`frontend/src/features/wechat/WeChatWorkspace.vue`、`frontend/src/styles/settings.css`、`frontend/src/styles/wechatWorkspace.css`。

静态预览不包含真实账号、Cookie、API Key 或网络请求。
